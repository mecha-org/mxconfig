# mxconfig_dart

Dart bindings for [mxconfig](../../README.md), over the `mxconfig-ffi` crate through `flutter_rust_bridge`.

```dart
import 'generated/demo.dart';

final demo = await Demo.open();
await demo.colors.setAccent('#ff0000');
demo.changes().listen(print);
```

Generate typed classes with `mxconfig-codegen dart <schema> lib/generated`. See [getting started](../../docs/getting-started.md#use-it-from-dart-or-flutter) for setup, and [the reference](../../docs/reference.md#the-dart-settings-api) for the full API. To reach mxconfigd, add [`mxconfig_dbus`](../mxconfig_dbus/README.md).

The native library is found through `libraryPath`, then `MXCONFIG_LIB`, then the platform loader.

`lib/src/rust/` is generated by `flutter_rust_bridge_codegen generate` from the repository root. Don't edit it by hand.

## Testing

```sh
MXCONFIG_LIB=../../target/debug/libmxconfig.so dart test
```

Build `mxconfig-ffi` first.
